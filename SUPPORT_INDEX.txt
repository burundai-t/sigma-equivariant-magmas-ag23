RP PREPRINT SUPPORT INDEX
=========================

Legacy alias
------------
Older support artifacts and some frozen L1/L2/L3 notes use PAB for the selected
right-row projection magma. In the current manuscript this object is denoted RP.
Thus PAB = RP as a support-package alias.

Purpose
-------
This file maps the current manuscript to the repository support layers and
reviewer-facing verifier commands. It is a navigation index, not a second
mathematical manuscript.

Canonical manuscript
--------------------
Mathematical source:
  paper/main.tex

Compiled manuscript:
  paper/main.pdf

Build command:
  cd paper
  lualatex -interaction=nonstopmode -halt-on-error main.tex
  lualatex -interaction=nonstopmode -halt-on-error main.tex
  lualatex -interaction=nonstopmode -halt-on-error main.tex
  cd ..

The layer notes inside L1/, L2/, and L3/ are frozen reference notes. For theorem
wording, use paper/main.tex. For support paths and commands, use this index and
README.md. Historical L2 wording that treats the global Omega' H-certificate as
open is superseded by the separate mathcal_H/ bundle; H is still not a Layer-2
selector dependency, since RP and row-complement share the same pure-frontier H
profile.

Full recomputation routes
-------------------------
Full recomputation commands can be long. They write to mathcal_H/runs/, which is
ignored by .gitignore. Append --dry-run for a no-work preflight if supported by
the runner.

H1 full recomputation:
  cd mathcal_H
  PYTHONDONTWRITEBYTECODE=1 python3 h1/run_h1_evaluator.py     --start-index 0     --end-index 0     --run-dir runs/h1_full     --force     --self-test
  cd ..

H2 full pure-frontier recomputation:
  cd mathcal_H
  PYTHONDONTWRITEBYTECODE=1 python3 h2/run_h2_frontier.py     --depth 9     --start-offset 0     --end-offset 0     --run-dir runs/h2_full     --force
  cd ..

H4 full recomputation:
  cd mathcal_H
  PYTHONDONTWRITEBYTECODE=1 python3 h4/run_h4_classifier.py     --start-index 0     --end-index 0     --run-dir runs/h4_full     --force     --self-test
  cd ..

Local run-output policy
-----------------------
Command transcripts, integrity checksums, and recomputation outputs are local
reviewer artifacts rather than bundled release files. New recomputation outputs
should be written under runs/ or mathcal_H/runs/ and are ignored by .gitignore
unless intentionally promoted.
